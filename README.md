# AETHERIA

**An interactive 3D discovery lab** — a spatial journey through a floating archipelago of emerging technology.

Four persistent regions suspended in one continuous sky. Fly between them on a scroll-driven camera spline, hunt hidden nodes, recover Aether Cores, and decode the citadel.

---

## Regions

| # | Region | Route | What lives there |
|---|--------|-------|------------------|
| 01 | **Gate of Origin** | `/` | Arrival. The Monolith, and the secret node that starts everything. |
| 02 | **The Crucible** | `/playground` | A shader lattice you tune to resonance. |
| 03 | **Archive of Artifacts** | `/vault` | Sealed objects, each with a developer commentary. |
| 04 | **Citadel of Knowledge** | `/codex` | The archive, and a terminal that is still live. |

## Quests

Five side quests are threaded through the realms. Progress persists to `localStorage`, so an Explorer's recovered cores survive a reload. Completing them unlocks the **Cyberpunk Neon** palette, which reskins both the DOM and the WebGL layer from a single source of truth.

## Stack

- **Next.js 15** (App Router, Turbopack) + **React 19**
- **three.js 0.186** + **@react-three/fiber** — the scene layer
- **@react-three/postprocessing** — bloom, chromatic aberration, vignette
- **zustand** — graphics, quest and UI state (persisted)
- **GSAP + ScrollTrigger + Lenis** — smooth scroll driving the camera splines
- **Howler.js + WebAudio** — sample bank and a spatial poly-synth
- **Radix UI + Tailwind** — HUD primitives

### Graphics tiers

A synchronous WebGL probe (`src/lib/gpu.ts`) picks a tier *before* the Canvas mounts, so particle counts are never rebuilt mid-session. Each tier sets its own budgets for stars, dust, motes, bloom, DoF, SSAO, shadows and DPR. Manual overrides from the HUD always win.
